白龙桌宠增强版｜当前新增功能说明（v0.7.1）

原项目来源：https://github.com/jingh12312-rgb/bailong-desktop-pet
以下以最初使用的白龙桌宠 0.3.3 为基线，仅列出增强版目前仍保留的新增功能和改进。

1. Codex 实时联动
工作动作定期续播：思考、阅读、编辑、执行和检查保持对应动作与适度停顿，默认每12秒检查一次；Codex实时任务元数据确认长时间思考仍在进行，续播不会刷新气泡文字或打断当前动作。
自动识别本机 Codex、会话目录和 CLI，展示思考、执行、等待输入或审批、正在压缩上下文、回复、完成和中断等状态；支持连接检测和自定义 Codex 路径。状态详情使用“正在编辑文件”“运行了命令”等简短操作摘要。

2. 多会话状态与已读提醒
最多同时显示两个会话，优先兼顾未读完成与进行中任务，更多会话可通过 +N 切换。正常气泡点击会话名可直接跳转到对应的 Codex 对话；跳转不提前确认已读。实际对话名固定在左侧，过长时缩短为关键词，重名时附短编号；右侧摘要各自独立滚动。完成行带圆角背景。子会话继承历史不会被误识别成独立主会话，旧版本残留的子会话完成提醒在启动时自动清理。进行中图标采用三个空心圆围绕中心旋转，同时反复向外展开、向内收拢；正常气泡和缩小胶囊沿用各自主题色。进行中三圆连续过渡为对应状态：任务完成时在约480毫秒内减速收拢并变成感叹号，成形后轻晃约1.2秒，再静止保留待查看提醒；点击确认后变成对勾，约1秒确认提示结束后，如仍有任务则恢复三圆旋转。Codex 本机实时通道明确标记等待输入或审批时，图标变成横向呼吸三点；任务中断变成暂停符号，继续执行时恢复旋转。快速状态变化从当前形状续接，重复状态不重启动画；隐藏时暂停运动时钟与刷新。未读完成提醒继续优先显示。点击确认、在对应会话回复，或看过完成回复并稳定确认约 4 秒后，可清除对应提醒。

3. 双形态头顶气泡
提供正常信息气泡和灵动岛式缩小气泡。收回保持额度与图表进度，原生窗口切换由短暂末帧覆盖衔接；覆盖不接收输入或焦点。缩小模式只显示简短任务状态，旁边提供闲聊和额度百分比圆环，点击胶囊打开正常面板。自动模式在长时间无任务更新或 Codex 关闭后收起，新状态到来后恢复；固定缩小模式由用户手动展开。设置、聊天、详情和日报打开时保持当前操作界面。

4. 清晰标注的额度卡片
正常面板按账户实际提供的一项或两项额度，分别显示“5 小时剩余”“周剩余”、百分比、进度条与独立重置倒计时；支持自动及手动刷新、低额度提示。额度过期后提示待刷新，未知数据不当作 0%。今日 Token 单独显示实际消耗值，点击直接打开右侧今日 24 小时曲线。缩小气泡的40像素额度圆采用270°单条开口弧，底部留白、圆润端点，使用浅底紫色和低额度警示色。中心数字较大、百分号较小，整组按实际字体边界居中，仅显示百分比或未知符号“—”，不显示周期文字；显示四舍五入整数，非零但不足1%显示“<1%”，未满100%时最多显示99%。无障碍说明保留精确百分比和周期，点击仍打开详情。优先显示五小时额度，耗尽后切换周额度，五小时窗口到期后重新优先查询并等待真实数据。

5. 额外重置公告
接入 Codex Resets 的公告信息，提示新重置消息；待落实安排优先展示并跨重启保留，站点确认落实后恢复 Token 卡片。支持公告与 Token 卡片切换、手动刷新和查看来源；选中背景横向滑动，切换复用控件并保留额度动画。站点公告与个人账户的实际到账状态分别显示。

6. 本机 Token 用量统计
从本机可读日志增量统计 Token，支持全部、30 天、7 天柱状图及今日 24 小时分区曲线。小时曲线统一从底部“今日 Token · 24h”进入，右侧不再重复放置24h按钮；当前小时视图会高亮底部入口。处理累计计数、重复日志、归档和跨月，保留统计历史；未来时段留空，并说明记录不完整的情况。

7. 独立唤出的 Token 日报
日报平时隐藏，由独立按钮唤出，在气泡上方对齐展开。概览包含累计会话数、活跃天数、Token 总量、最常用模型（按累计 Token 量），以及昨日消息数、高峰时段和 24 小时消耗曲线。模型页可按全部、30 天、7 天查看截至昨日的模型用量、占比及可识别的输入/输出分项，并按模型筛选图表。用量类比文案随真实累计数据变化。日报小字加粗、加深颜色，滚动条提前占位；图表缓存静态文字和轨迹，在显示就绪后播放轻量入场动画；切换范围或模型复用图表，后台刷新保留动画进度和滚动位置。

8. 动作调度与桌面互动
新增自动随机动作、自主移动、朝向控制、按压回弹、拖拽惯性、摩擦及边界反弹。支持按 Codex 状态选择现有动作，等待当前动画播完后再检查最新状态，配合间隔、冷却和去重，减少频繁打断。自动动作和提醒静音，主动点击互动时才播放音效。

9. 原有动画质量修复
修复原有 15 段动画的透明杂边与噪点、动作和待机的尺寸差异、回位衔接及切换清晰度变化；改进帧计时、缩放和高 DPI 显示的一致性。

10. 集成聊天、设置与详情
聊天、模型服务配置和设置集成在桌宠面板内，保留草稿和未应用设置。设置仅提交改动字段，外部开关同步到未编辑项，同字段冲突有提示；自启可单独保存和重试。闲聊支持多个 OpenAI 兼容服务、流式回复、停止、重试、多会话和按角色保存记录；支持自定义人设、上下文上限与自言自语台词。详情按额度、Token、重置和图例分类，数字与英文使用随包提供的 Chakra Petch 字体。

11. 桌面控制与角色扩展
支持 Windows 登录自启、托盘管理、整体显示/隐藏、置顶、锁定移动、透明区域点击穿透和全角色穿透。可调角色大小、播放速度、动作间隔、随机频率、移动速度与范围；保存位置和朝向，适配多屏及 DPI 变化。支持角色包导入、完整性检查、热切换、分类动作预览和角色独立偏好。

12. 动效、性能与安装维护
状态滚动、气泡高度、模式切换、聊天/设置、详情和日报均有过渡动画；胶囊和卡片采用同一连续表面变形，状态图标沿一条路径移动，两个圆形按钮独立进出；面板展开与收缩轻微回弹，日报关闭与隐藏气泡在消失前回弹收走，额度进度条、柱状图和曲线支持入场轨迹动画。采用后台按需解码与有界缓存、状态局部更新、未变化日志跳读和单次诊断写入；额度倒计时仅在显示内容改变时更新，避免无意义的每秒重绘。提供免装 Python 的 Windows x64 一键部署包，双击自动安装或升级并启动，保留已有自启选择；另提供升级保留配置、旧版本回退、保留用户数据的卸载、设置备份恢复和诊断导出。

使用条件：Codex 状态、额度及统计使用目标电脑自己的登录和本机记录；闲聊需自行配置模型服务及密钥。Token 统计范围为本机可读日志。

日报说明字号分层、紧凑布局，27本书各自英文版本的原文参考计数；每次打开日报随机一本，图形按钮手动换书。点击缩小胶囊进入正常面板；会话名跳转具备悬停与按下反馈。正常面板将额度与今日 Token 分开说明，保留右侧图表和公告切换；当前顶栏使用28×28像素纯图标按钮，保留悬停、按下、键盘焦点与无障碍名称；标题按剩余宽度自适应。

13. 统一的操作入口与记录保护
人物右键精简为8个常用主层入口，托盘5项专注恢复可操作和显示管理；长期偏好集中到常规、动作、连接、角色、维护五类设置，高级参数与台词可折叠。返回恢复进入前的视图，头部收起回正常气泡；状态导航和桌面开关明确分隔。额度查询统一静音。聊天清空、删除移入管理菜单，原面板内确认后执行；删除服务、清除密钥也需确认，切换服务保留未保存输入。

14. 界面操作层级与连接健康
主操作、辅助操作、危险操作分层；常用图标保留清晰图形、无障碍名称和独立点击区，编辑页有可见键盘焦点与 Ctrl+S 保存。连接页分别展示任务、提醒、自动已读、额度、Token、压缩状态的可用性、最近成功时间和简短原因；断开或格式变化不会误清提醒、未知数据不冒充零。可在界面选择并验证 Codex 数据目录与 CLI，重启桌宠后生效，环境变量优先。
日报累计与昨日指标分区；模型选中标签、清除筛选和占比分母持续可见。源日志异常时保留历史图表并说明缓存或不完整。正常气泡宽268像素，高度按当前内容布局；日报概览根据完整内容测量高度，正常空间下完整展开，模型页沿用概览高度并在内容超出时滚动。

15. 长期监测、闲聊流式优化与安装启动确认
多会话监测按共享身份与优先级公平轮换，已知活动日志持续跟踪并支持转入归档，名称与已读查询分批覆盖。未读列表完整保留，完成ID使用本机账本去重；正常气泡仍最多显示两个会话。
缓存目录发现并定期全扫兜底；闲聊流式文本合并追加，保留上文选区和滚动位置。高级性能聚合默认关闭。原动作与窗口过渡时长保留，状态图标循环按当前版本适度提速。
一键安装先校验载荷，再等待新版窗口与本地服务就绪，确认后更新入口；失败恢复旧入口和原桌宠，中断可在下次安装恢复。旧安装版本与用户数据保留。

16. 保持画面质量的包体优化
15组动画逐帧无损重编码，完整RGBA、720像素画布、帧数、播放时序及过渡保持；资源约减少10.2%。维护入口复用主程序运行库，不再保存整份安装器。FFmpeg改为仅在导入WebM时使用的本机可选工具；WebP/GIF直接导入。
新版本用内容哈希与NTFS硬链接共享相同动画，记录版本引用并在复用、回退时校验；不支持硬链接时保留独立文件。旧安装版本与原素材不作自动清理。默认包裁剪无用的部分Qt依赖，仍可离线一键部署。

17. 卡片展开动效统一
日报以胶囊形状展开为卡片；设置的高级参数、连接路径与报告，以及聊天/服务的确认卡片共用连续形变、轻回弹和分阶段内容入场。快速反向操作从当前位置衔接，切页后释放快照、保留草稿；统计后台刷新不反复播放动效。周额度采用低饱和蓝灰，与五小时紫色区分；缩小额度环同步，低额度警示保留。

18. 窗口收尾与残影修复
日报缩回主面板上沿，隐藏前清空末帧；面板位置、尺寸和内容在暂停绘制期间统一交接。关闭末段持续收拢，避免再次长回造成闪烁；设置折叠区预留滚动条宽度，减少内容挤压跳变。

19. 胶囊与主面板稳定切换
主容器使用不越界的临界阻尼缓动，覆盖胶囊与正常气泡、胶囊直接打开完整详情/聊天/设置及返回。过渡中的状态文字更新在结束后增量应用，减少落地时整页重建。

非整数显示缩放按物理像素对齐，完整末帧平滑交接；安装包提供完整ZIP，不再生成分卷。

日报显示补充：概览完整展开；模型页按需要滚动，切换保留统一高度。
日报Y轴按字体实际尺寸布局；正常周额度条按剩余连续变色。

20. 统一刷新与精简顶栏
正常气泡和详情使用统一刷新入口，同时更新额度、Token 与额外重置公告；日报保留一个刷新入口，更新概览和模型统计。刷新采用单弧箭头，局部旋转并轻微呼吸，完成后短暂显示对勾；失败保留原数据并显示失败反馈，不冒充刷新成功。顶栏操作改为28×28像素的纯图标按钮，保留悬停、按下、键盘焦点和无障碍名称。运行时标题简化为 Codex，多会话显示数量；待输入、待确认、待查看和已中断使用短状态，标题按照按钮实际占位分配空间。缩小胶囊继续显示简短状态。状态三圆与刷新循环提速约20%：状态旋转周期3秒、呼吸周期2秒，刷新旋转周期2秒；完成提醒常驻、确认停留和窗口过渡规则保留。
实时任务状态继续自动接入；手动刷新不会重播整个面板或图表入场动画。同一轮刷新按各数据源结果分别完成，失败项保留旧数据。

界面小改（v0.7.0）：大卡片删除无交互的“桌面”分组文字，保留置顶、移动等真实开关。

视频全屏自动让位（v0.7.0）：视频全屏时，人物、气泡和已打开的所属窗口临时取消置顶并退到视频后面；退出全屏或切换应用后恢复当前置顶偏好。常规设置可关闭本功能，默认开启。手动关闭始终置顶后不会被自动重开。只对覆盖桌宠所在屏幕的前台全屏视频生效。播放器按常见进程与全屏客户区识别；浏览器依赖系统提供的视频角色或播放、全屏、时间进度控件组合，不读取网页正文、标题或网址。普通最大化、非视频网页F11和后台音乐不作为触发依据。部分网站隐藏或不提供可访问控件时可能识别不到，保持原设置。详见“视频全屏让位说明.txt”。

Firefox全屏视频修复（v0.7.0）：修复Firefox + B站全屏视频漏检：改用Firefox IA2接口的真实video节点、可见状态与屏幕位置，不再依赖播放器按钮或进度条。保留用户确认的优先级：未确认的任务完成提醒高于视频让位，提醒出现时重新置顶；点击状态图标确认或在Codex看过回复、未读提醒全部消除后，视频仍全屏则继续让位。用户主动关闭始终置顶时，不因完成提醒自动重开。补充检测阶段、耗时、原生层级执行结果与提醒优先状态，便于定位实际问题。详见“Firefox视频全屏修复说明.txt”。


白龙桌宠增强版 v0.7.0｜新增动作修复与 Codex 工作联动（UI60）
原项目来源：https://github.com/jingh12312-rgb/bailong-desktop-pet
上游动画来源版本：v0.4.1。

新增五段工作动作：收到任务、处理任务（敲电脑）、整理归档文件、翻阅工作资料、放大镜查看细节。
新增五段互动：偷吃（吃饼干）、比心、龙族契约、宝藏收藏、逆鳞信任。
新增十段采用透明边缘清理、独立特效保护、克制的线条增强和头部特征尺度校准；完整保留原动作帧与约24fps，在首尾加入与现有主待机一致的空间过渡。原有十五段修复素材保持。

Codex联动规则：仅真实新回合排队一次“收到任务”，历史恢复和子会话不冒充新任务；阅读/研究用翻资料，编辑/整理/压缩用文件动作，执行命令用敲电脑，检查/验证/失败排查用放大镜，整理回复用文件动作。兼容包装工具的公开操作摘要。其他角色缺少工作动作时保留旧映射，不随机替代。
现有动作播完、冷却后才读取最新状态；收到反馈与完成庆祝都不强制截断动作。完成提示仍及时显示，庆祝等待安全边界；完成回合不再继续播放其旧工作状态，其他会话继续工作。自动动作无声音和额外动作台词；主动互动按已有声音偏好反馈。待输入或审批不会持续播放工作动作。

手动动作菜单增加工作分类；吃饼干/比心/信任也可进入点击回应，其他互动进入闲置随机与手动菜单。五段工作只在对应工作状态或手动选择时使用，不混入普通闲置随机池。

播放继续使用后台六帧队列和有预算缓存，不采用上游全量预加载。新素材经过逐帧无损打包验证；升级保留用户设置、角色偏好、聊天与回退版本。
