Codex&GPT桌宠数据中心 v0.8.3｜Windows x64
原项目来源：https://github.com/jingh12312-rgb/bailong-desktop-pet
增强版仓库：https://github.com/Wunsch2048/codex-bailong-desktop-pet

首次安装 / 从旧版升级
1. 完整解压 bailong-desktop-pet-0.8.3-windows-x64.zip。
2. 双击“白龙桌宠-0.8.3-一键部署.exe”。无需 Python 或管理员权限。
3. 安装器会关闭旧桌宠、备份设置/聊天/统计、校验并启动新版本，确认就绪后切换入口；保留旧版回退。不要关闭正在部署的窗口。
4. 在本机安装并登录 Codex，发送一次消息；桌宠自动识别连接，通常无需重启 Codex。设置 → 连接 → 检测连接与额度可检查各项能力。

画质与显示
默认512px轻量素材。设置 → 角色与动作 → 内置白龙画质，可主动下载并切换720px高清；下载或校验失败保留原画质。自定义角色不被替换，高清按素材内容ID缓存，不随代码版本重复下载。
设置 → 常规与外观，可隐藏人物，仅保留卡片；也可使用“极简：额度百分比”。原人物/卡片显示偏好随升级保留。

软件更新
设置 → 维护与数据 → 软件更新。自动只检查，下载安装需主动点击，保留更新说明与暂停续传。
从v0.7.9及更早版本升级到本版请使用完整包。后续支持程序小包的版本，在素材相同且校验通过时可只下载程序包；素材不匹配或损坏时用完整包。program.zip和program.json由内置更新器使用，不是独立完整安装器，不能解压后直接运行。高清资源与程序包分开维护。

本版功能
额外重置卡片显示预计剩余小时与分钟，整小时保留00分，不足一分钟显示<1分钟；每分钟更新且不改变卡片尺寸。卡片右上角可打开Codex Resets公告网站，点击倒计时仍打开桌面端详情。
修复Codex会话已读提醒：按具体已结束轮次判断，Codex明确显示已读并稳定后消除旧轮次提醒；其他未读会话及正在进行的任务仍保留。

回退与数据
安装目录：%LOCALAPPDATA%\Programs\BailongEnhanced
用户数据：%LOCALAPPDATA%\BailongEnhanced
“安装管理.cmd”、安装目录的安装管理程序或系统卸载入口可管理回退/卸载。回退后退出当前桌宠，再用快捷方式启动。升级保留用户数据、画质偏好与自动启动开关；失败恢复旧入口。新安装默认登录自启，可在设置关闭。
未读任务完成提醒优先于全屏视频让位，确认后继续让位；这是既定行为。

数据范围
额度依赖本机Codex有效登录；Token统计仅覆盖本机可读日志。Codex Resets为第三方公告，不等于账户已实际重置；未知值不当作零。
闲聊需自行配置模型服务和密钥。本包不包含开发者凭据、会话内容、聊天记录、统计数据库或API密钥。
