# 程序补丁包 1.0.1（发布草稿）

尚未公开发布，以下是候选更新说明。安装请使用 [v1.0.0 公开版本](https://github.com/Wunsch2048/codex-bailong-desktop-pet/releases/tag/v1.0.0)。

- 新增 Windows 桌宠接入 WSL Codex：读取会话、Token 和完成状态，调用 Linux CLI 查询额度，并打开 Linux 会话。支持选择发行版、用户及路径。
- 补齐程序与动画补丁的独立更新流程，两类补丁共用公开版本号；已有动画无需重复下载。
- 额度对比说明补充：至少观察到 5 个百分点的额度下降才估算总量。历史比较还要求覆盖 20 个百分点、至少 3 个不同读数及足够一致的模型与数据条件，避免把不完整记录当成缩水。
- 修复额度对比切回概览时数据面板变短的问题。

![数据面板切换](../media/data-panel-1.0.1.gif)

动图使用模拟统计数据录制原生测试窗口，展示页面切换，不作为显示帧率证明。

## 下载

已有用户优先在软件内更新，或下载“程序补丁安装器 1.0.1”。程序 ZIP 与 JSON 供软件内更新使用，不要直接解压覆盖安装目录。

安装器不包含人物动画：已有用户复用可校验的本机素材，新用户先获得卡片程序，可在设置中下载人物素材。安装器保留设置、统计与回退版本。本次没有重新上传动画资源。

## WSL 使用与验证边界

设置 → Codex → 连接路径与检测报告，选择 WSL、刷新并选择发行版，验证并保存路径后重启。详见 [WSL 接入说明](https://github.com/Wunsch2048/codex-bailong-desktop-pet/blob/main/docs/WSL.md)。

WSL 完成提醒需手动确认，未实现 Linux 进程启动/退出联动。本机没有安装 WSL，已通过适配器、传输夹具及 Windows 界面检查；真实发行版登录、共享目录与额度查询仍需实机确认。因此 WSL issue 保持开放。

132 项定向回归（含 20 项 WSL）已在 Windows 通过，发布前另验证冻结模块、安装器准备与文件校验。原项目：[jingh12312-rgb/bailong-desktop-pet](https://github.com/jingh12312-rgb/bailong-desktop-pet)。
